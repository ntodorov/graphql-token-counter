# GraphQL Token Counter

A simple web application that allows you to count tokens in GraphQL queries.

## How to Use

1. Open `index.html` in your web browser
2. Enter your GraphQL query or mutation in the text box
3. Click "Count Tokens" to analyze your query
4. View the total token count and detailed breakdown

The application uses the official GraphQL library to tokenize and analyze queries, providing an accurate count of all tokens in your GraphQL operations.

## Features

- Token counting for any valid GraphQL operation (queries, mutations, etc.)
- Detailed breakdown of each token type
- Modern, clean interface
- Error handling for invalid GraphQL syntax
